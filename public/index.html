Things I've built

Infrastructure, games, bots, and browser tools — all self-hosted.

Hackatoa Games Platform

A self-hosted browser games platform — free, no account, no ads. Six original games: Infinisweeper (infinite shared Minesweeper with global leaderboard), 1v1 Minesweeper (competitive head-to-head), Battleship (AI + multiplayer), Cards Against Hackatoa (browser CAH with voting rounds and community packs), Sys32 Roulette, and Tic-Tac-Toe Online. All running on the homelab.

All Games Infinisweeper 1v1 Minesweeper Cards Against Hackatoa

WikiRoll · Discord Collection Bot

A Discord bot where server members roll, claim, and trade characters sourced from Wikipedia and 150+ Fandom wikis — Naruto, Marvel, Pokémon, Elden Ring, and more. Wishlist characters, boost sources for 3× pull weight, vote for bonus rolls. Built with discord.js, SQLite, and the MediaWiki API.

Website Add to Discord Vote on top.gg GitHub

Lamar Bot · GTA V AI Discord Bot

Lamar Davis from GTA V, living in your Discord server. Powered by Groq's llama-3.3-70b — responds in character with persistent per-user memory so he actually remembers what you said. Attack commands, games, stories, and zero chill.

Website Add to Discord GitHub

Canvas Messenger

Chrome and Firefox extension that adds Discord-style messaging to Canvas LMS — DMs, group chats, and class-wide channels, all end-to-end encrypted. Built around a Node.js relay backend with WebRTC signaling to work within Canvas's platform restrictions.

GitHub Relay

Clip Forge · Browser Video Editor

A fully browser-based video editor — no uploads, no server, no account. All rendering happens locally using FFmpeg compiled to WebAssembly. Multi-track timeline with video, audio, text, and shape layers, transitions, voiceover recording, and per-track volume control.
