Hackatoa.com · main site

The volcano-themed home base. Built with vanilla JS and CSS — no frameworks — featuring a time-driven background that shifts between day, sunset, and night based on your local clock. Deployed via GitHub Actions to self-hosted infrastructure on a Proxmox homelab.

Hackatoa Games

A self-hosted browser games platform — free, no account, no ads. Infinisweeper is an infinite shared Minesweeper board anyone can play simultaneously. 1v1 Minesweeper is a competitive head-to-head race. Tic-Tac-Toe Online is the classic 3×3 played live with a friend. All running on the homelab.
